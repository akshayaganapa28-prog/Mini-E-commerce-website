# ShopEasy - Mini E-Commerce Website

## Project Objective
The objective of this project is to create a responsive and interactive shopping website using HTML, CSS, and JavaScript.

## Project Overview
ShopEasy is a simple online shopping website where users can view products, search for products, filter by category, and manage their shopping cart.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages

## Main Features
- Display products
- Search products
- Filter products by category
- Add products to cart
- Increase and decrease quantity
- Remove products from cart
- Calculate total price
- Save cart using browser storage
- Responsive design

## Project Files
- index.html - Website structure
- style.css - Website design
- script.js - Website functionality
- README.md - Project information

## How to Run
1. Download or clone the repository.
2. Open index.html in a browser.
3. Search for products and try the shopping cart.
